# Vault

Vault Obsidian z notatkami, zadaniami i decyzjami wokół Bazy.

Otwórz katalog `vault/` jako vault w Obsidianie (*Open folder as vault*) albo czytaj pliki bezpośrednio na GitHubie — to zwykły markdown.

Punkt wejścia: [`00 Start tutaj.md`](00%20Start%20tutaj.md)
Co robić teraz: [`01 Zadania/Tablica zadań.md`](01%20Zadania/Tablica%20zada%C5%84.md)

| Katalog | Zawartość |
| ------- | --------- |
| `01 Zadania` | Jedno zadanie = jedna notatka, ze statusem i priorytetem |
| `02 Projekty` | Dokumentacja: architektura, stack, model danych |
| `03 Obszary` | Tematy przekrojowe: bezpieczeństwo, wydajność, CI/CD, RODO, jakość |
| `04 Przeglądy` | Przeglądy kodu, datowane |
| `05 Decyzje` | ADR-y |
| `06 Runbooki` | Deploy, incydenty |
| `07 Dziennik` | Notatki dzienne |
| `99 Szablony` | Szablony |

Vault działa bez wtyczek. **Dataview** ożywia tabele zadań — zalecana, ale nie wymagana: pod każdym zapytaniem jest lista statyczna.

> Nie umieszczaj tu sekretów ani danych osobowych — repo może być publiczne.
